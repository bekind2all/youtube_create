## 1. 파악한 것 (기획 전 읽은 자료)

- **지난 영상(10/2~10/3)**: 5가지 = ① 모델은 그대로, 강도만 조절 ② 일(주제)이 바뀌면 새 대화 ③ 자료는 필요한 것만 ④ 답은 분량을 정해서 ⑤ 안 쓰는 건 끈다. 핵심 전제는 "짧은 메시지에도 AI는 이전 대화를 다시 읽고 토큰을 쓴다". 이번 편은 이 전제가 **왜** 그런지(토큰이 뭔지)를 설명하는 앞 편이다. ※ 자막 원문은 이 작업 환경에서 유튜브 접속이 막혀 제목·설명·챕터로만 확인했다.
- **책(사진 3장, Chapter 5, 88~90쪽)**: ① 토큰 = AI가 언어를 처리하는 가장 작은 단위(단어·단어 일부·글자 하나) ② 'run/running/runner/runs'를 뿌리와 가지로 나눠 배우는 **서브워드 토큰화** ③ 같은 뜻이라도 한국어는 영어보다 **두세 배** 토큰 소모("Hello, how are you?" 약 6개 vs "안녕하세요, 잘 지내세요?" 12개 이상) ④ 이유는 BPE가 영어 데이터 중심으로 학습됐기 때문(Llama 3 학습 데이터 95%가 영어·코드) ⑤ 교훈: 한국어 프롬프트는 '압축'이 중요하다("-하는 것이 좋겠습니다" → "-하세요"). 박스 문장: "문장을 압축하여 '작업 기억 공간'을 확보하라."
- **10/9 모션그래픽 강의 샘플 ② '용어 설명(토큰)' 30초**: 모프(글자→블록), 반반 화면(비유 vs 실제), 도식 쌓기, '휙' 효과음. 이번 편은 그 문법을 재사용하되, **한국어 차이·돈·무료 한도** 세 덩어리를 더해 60초로 늘린다.
- **오늘AI 브랜드 문서(9/27)**: 첫 3초에 결론, 글자 먼저 → 노란 밑줄, 화면엔 요지·수치, 음성엔 연결 설명, 세로 안전영역(자막 위쪽 가운데, 오른쪽·아래 버튼 자리 비움), 캐릭터는 기본 미등장.
- **사용자 교재 원고(AI교재_원고, 9/22~9/28)**에 이미 같은 톤의 토큰 설명이 있다("LLM은 글을 '토큰'이라는 조각으로 잘라서 읽습니다", strawberry 예). 말투를 여기에 맞췄다.
- **"출근길 1분 AI공부"**: 저장소·Drive·Notion·채널 검색에서 이 이름의 기존 편을 찾지 못했다. 새 시리즈명으로 보고 제목 앞에 붙이는 안으로 썼다. (확인 요청 ③)

## 4. 나레이션 전문 (읽기용, 쉬운 말)

> **S1** AI 요금표에 자꾸 나오는 '토큰'. 대체 뭘까요?
>
> **S2** AI는 글을 우리처럼 단어로 읽지 않아요. 레고 블록처럼 조각내서 읽죠. 그 조각 하나가 토큰이에요.
>
> **S3** '달리다, 달리기, 달렸다'를 따로 외우는 대신, '달리'라는 뿌리에 꼬리만 바꿔 끼우는 식이죠. 이걸 서브워드 토큰화라고 해요.
>
> **S4** 그런데 한국어는 좀 억울해요. 영어는 흔한 단어가 통째로 한 조각인데, 한국어는 잘게 쪼개지거든요. 예전엔 같은 말도 영어보다 두세 배 토큰을 썼어요. 지금은 많이 줄었지만, 그래도 조금 더 써요.
>
> **S5** 토큰은 세 번 들어요. 내가 보내는 글은 입력, AI가 속으로 생각하는 건 추론, 답은 출력 토큰. 요금은 이 개수로 매겨지는데, 보통 출력이 입력보다 몇 배 비싸고, 생각한 것도 출력으로 쳐요.
>
> **S6** 무료는 돈 대신 한도가 닳아요. 대화가 길어질수록 AI가 앞 내용을 매번 다시 읽거든요. 그래서 금방 차죠. 거꾸로 말하면, 토큰 아끼는 습관만 있으면 무료도 유료처럼 쓸 수 있어요.
>
> **S7** 짧고 또렷하게 묻기, 주제 바뀌면 새 대화. 나머지 다섯 가지는 지난 영상에 있어요. 오늘AI, 함께 Go!

- 음절 약 365개. 승인된 숏폼 속도(초당 5.5~6음절)로 **약 61~67초**. 실제 음성이 68초를 넘기면 S4의 셋째 문장("예전엔 같은 말도…")을 자막으로만 남기고 음성에서 뺀다. 'GPT-3.5·4 세대'라는 표현은 S4 화면 라벨에만 둔다.
- "두세 배", "조금 더", "몇 배"처럼 **범위로 말하고 단정 숫자는 화면 자막에만** 둔다(출처별 수치가 달라서).
- 강사 말투("배워보겠습니다", "따라 하세요") 없음. 결과 보장 표현 없음.

- 효과음: 자막 팝 '휙' 1개씩, S2 조각 떨어질 때 '톡', S6 바 줄어들 때 낮은 '틱'. 출처는 CREDITS.md에.

직접 측정 스크립트(로컬 PC, 1분): `pip install tiktoken` 후 아래를 실행하면 GPT-3.5·4 세대(`cl100k_base`)와 GPT-4o 이후(`o200k_base`)의 영어·한국어 토큰 수가 나온다. 결과를 S4 자막 수치로 쓰면 "직접 세어 봤더니"라고 말할 수 있다.

```python
import tiktoken
pairs = [("Hello, how are you?", "안녕하세요, 잘 지내세요?"),
         ("I drank coffee at a cafe today.", "나는 오늘 카페에서 커피를 마셨다."),
         ("Explain this.", "이것을 설명해 주세요."),
         ("It would be nice if you could explain this.", "이것에 대해서 설명을 해주시면 감사하겠습니다.")]
for name in ["cl100k_base", "o200k_base"]:
    enc = tiktoken.get_encoding(name)
    print("==", name)
    for en, ko in pairs:
        e, k = enc.encode(en), enc.encode(ko)
        print(f"{len(e):3d} vs {len(k):3d}  x{len(k)/len(e):.2f}  {en} / {ko}")
```

## 7. 무료 / 유료 사용자 포인트

- **무료**: 요금 대신 **한도**가 토큰으로 닳는다. 긴 대화 = 매번 앞 내용 다시 읽기 = 한도 소진. 그래서 "짧고 또렷하게, 주제 바뀌면 새 대화" 두 가지만 지켜도 체감이 다르다. 영상 비중 S6+S7(약 17초).
- **유료**: 돈으로 직접 나간다(구독은 한도가 더 클 뿐 구조는 같음). 출력·추론 토큰이 비싸므로 "답 분량 정하기, 강도 조절"이 효과적. 영상에서는 S5 한 문장으로만.
- 무료→유료 전환을 권하지 않는다. "습관이 곧 유료 효과"로 닫는다.

## 10. 용어 정리 (비개발자용)

| 용어 | 쉬운 뜻 | 영상에서 쓰는 말 |
| --- | --- | --- |
| 토큰(token) | AI가 글을 읽고 쓸 때 쓰는 조각 단위. 단어 하나일 수도, 단어 일부나 글자 하나일 수도 있다 | "조각" |
| 토크나이저(tokenizer) | 글을 토큰으로 자르는 규칙(사전). 모델·회사마다 달라서 같은 문장도 토큰 수가 다르다 | "자르는 규칙" |
| 서브워드 토큰화 / BPE | 자주 붙어 다니는 글자 조합을 하나의 조각으로 등록해 가는 방식. '뿌리+꼬리'로 배우는 원리 | "뿌리에 꼬리만 갈아 끼우기" |
| 입력 토큰 | 내가 보낸 글(질문·붙여넣은 자료·이전 대화 전체) | "내가 보내는 글" |
| 추론(생각) 토큰 | AI가 답하기 전에 속으로 생각하며 쓰는 토큰. 보이지 않지만 출력 요금으로 계산된다 | "속으로 생각하는 토큰" |
| 출력 토큰 | AI가 써서 보내주는 답. 입력보다 단가가 몇 배 비싸다 | "답" |
| 컨텍스트(작업 기억 공간) | AI가 한 번에 기억하며 볼 수 있는 글의 양. 대화가 길어지면 매번 이 전체를 다시 읽는다 | "앞 내용을 매번 다시 읽어요" |
| 사용 한도(usage limit) | 무료·구독 플랜에서 일정 시간 안에 쓸 수 있는 양. 토큰을 많이 쓰면 빨리 찬다 | "한도" |
