# 모션 수정 제안 · 토큰 편 (팔레트 01, B 미들 방식)

이 폴더의 TSX는 Remotion용 부품이다. `D:\영상제작\1분숏폼\01_토큰_대체그게뭔데\` 프로젝트에 복사해 쓰고, 장면 시작 프레임은 **실제 나레이션 타임스탬프**로 바꾼다. 아래 "주의"가 핵심이다.

## 장면별 제안 (지금 렌더에서 바꾸면 좋은 것)

| 장면 | 제안 | 왜 |
| --- | --- | --- |
| S2 | 문장이 한 줄로 떴다가 **조각이 반 박 간격으로 '착' 붙게**. 조각을 한꺼번에 띄우지 않는다 | '쪼갠다'가 움직임으로 보인다 |
| S3 | 한국어 블록은 **남색**, 영어보다 더 든 **초과 블록만 빨강**. GPT-3.5→지금으로 넘어갈 때 빨간 4개가 박 위에서 사라지고 숫자 12→8이 굴러감 | "한국어=손해"가 아니라 "초과분이 줄었다"로 읽힌다 |
| S4 | 추론 상자는 **점선**(안 보임), 동전은 출력 5 : 입력 1을 **반 박 간격 팝**. 요금 라벨에 "API 기준" | 5배가 말 없이 보인다. 구독자 오해 방지 |
| S5 | 질문 하나마다 **파란 띠가 이전 대화를 아래→위로 훑고**, 그때마다 한도 바가 더 많이 줄어든다(3회, 점점 크게). 35% 아래부터 진빨강 | "앞 내용을 매번 다시 읽는다"의 시각화 |
| S6 | 12블록이 6블록으로 **접히고** 숫자 12(빨강)→6(남색) | 압축의 결과가 숫자로 남는다 |

## 주의 (렌더 전 확인)
- 파랑 블록 위 글자는 남색. `textOn()`이 자동으로 고른다. 흰 글자는 대비 3.0:1로 규칙(4.5:1) 미달.
- 자막은 위쪽 가운데(y 300~900), 글자는 x 90~900 · y 220~1250. `Caption`은 이미 그 안에 있다.
- 글자가 자리 잡으면 **최소 1초 유지**. 팝(9프레임) 뒤에 `durationInFrames`를 30 이상 남길 것.
- 조각 나누기(S2·S6)는 설명용 예시다. S6 숫자(12→6)만 공식 토크나이저 캡처와 같게 맞추고, 라벨을 남긴다.
- 효과음: 자막 팝 '휙', 블록 '착'(짧은 나무 두드림), 한도 바 '틱'. 2.5kHz 로우패스, 출처는 CREDITS.md.
- BGM은 나레이션 아래 −18dB 이하로 덕킹.
