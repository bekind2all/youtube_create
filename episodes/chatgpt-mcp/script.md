# ChatGPT × 노션 MCP × PlayMCP — 기획·대본 초안

- 스타일 1(화면 중심) / 팔레트 02 / 롱폼 약 6~8분
- 상태: 인트로 모션 초안 완료(`intro.mp4`, 23초, 무음). 본편 녹화·음성은 PC 앱에서 진행
- ⚠ ChatGPT 커넥터 메뉴 이름·위치, PlayMCP 연결 주소는 녹화 때 실제 화면으로 확인 후 대본 수정

## 인트로 (모션 장면 ↔ 대본)
| 장면 | 화면 | 대본 |
|---|---|---|
| 1 | 할 일 메모 + 타이핑 문구 | ChatGPT한테 노션 정리까지 시킬 수 있다면 어떨까요? |
| 2 | 채팅 아이콘 클릭 → 주황 | 방법은 간단합니다. ChatGPT에 연결만 하면 됩니다. |
| 3 | 카드 3장 순서대로 | 오늘은 노션 MCP, 카카오 PlayMCP를 연결하고 실제로 써보겠습니다. |
| 4 | 토글 2개 켜짐 | 설정에서 연결을 켜면, 대화만으로 일을 맡길 수 있어요. |
| 5 | 코드 입력 vs 0 | 코딩은 한 줄도 필요 없습니다. |
| 6 | 오늘AI 로고 | 오늘AI에서 하나씩 같이 해볼게요. |

## 본편
1. **MCP가 뭔지 30초 설명** — AI가 외부 서비스를 쓰게 해주는 연결 통로.
2. **노션 MCP 연결** — ChatGPT 설정 → 커넥터(앱) 메뉴 → 노션 선택 → 노션 로그인·권한 허용(시청자 본인이 클릭) → 연결 확인.
3. **PlayMCP 연결** — playmcp.kakao.com에서 쓸 도구 담기 → 연결 주소 확인 → ChatGPT에 커넥터로 추가 → 카카오 로그인.
4. **실전 예시** — "이번 주 회의 메모를 노션 페이지로 정리해줘", "강남역 근처 점심 장소 찾아줘(카카오맵)".
5. **주의** — 요금제별 사용 가능 여부가 다를 수 있음, 권한은 필요한 페이지만 허용.
6. **마무리** — 구독·알림 안내.
