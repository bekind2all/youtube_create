# 오늘AI 브랜드와 모션

## 배색

승인 기준: 2026-09-27, 사용자 선택 팔레트 02.

| 역할 | HEX | 사용 |
| --- | --- | --- |
| 검정 | `#000000` | 강한 대비가 필요한 제한적 요소 |
| 남색 | `#14213D` | 밝은 배경의 제목·본문, 어두운 주요 배경 |
| 옐로 강조색 | `#FCA311` | 어두운 배경의 핵심 숫자·핵심 단어, 마커 강조 |
| 밝은 회색 | `#E5E5E5` | 보조 면, 구획, 약한 선 |
| 흰색 | `#FFFFFF` | 밝은 주요 배경, 어두운 배경의 본문 |

- HEX를 눈대중으로 다시 고르지 않는다. UI에서 옐로로 부르더라도 실제 값은 `#FCA311`이다.
- 한 장면에서 강조 이유가 분명한 곳에만 강조색을 쓴다. 흰 배경 위 작은 노란 글자를 본문으로 쓰지 않는다.
- 공식 로고와 제품 캡처는 원래 색을 유지한다. 브랜드색에 맞춘다고 제품 화면을 왜곡하지 않는다.
- 새로운 팔레트 번호를 요청받으면 사용자 제공 원본에서 정확한 코드를 확인하고 프로젝트 토큰에 반영한다.

## 공식 서비스·제품 로고

- 서비스나 제품을 소개하는 영상과 썸네일에는 **해당 서비스·제품의 공식 로고를 사용한다.** 도입이나 처음 설명하는 장면에서 대상을 바로 알아볼 수 있게 배치하고, 썸네일에서는 작은 화면에서도 식별될 크기를 확보한다. 모든 장면에 로고를 반복할 필요는 없다.
- 제품을 다루면 해당 제품 로고를 우선한다. 예를 들어 Claude 소개에는 Claude 로고를 사용하며, 모회사 로고만으로 대신하지 않는다. 비교 영상은 각 서비스의 로고와 이름을 정확히 짝지어 배치한다.
- 공식 브랜드 자료실·프레스킷·제품 사이트에서 현재 로고 원본을 확보한다. 사용자가 제공한 공식 자산이나 이미 출처가 확인된 로컬 자산도 재사용한다. 출처 URL과 확인일은 내부 자산 기록에 남긴다.
- 일반 서체로 제품명을 적거나 생성 모델이 그린 유사 심볼을 공식 로고로 취급하지 않는다. 이미지 생성에 공식 자산을 참조로 넣거나 최종 디자인에 원본을 합성하고, 완성 이미지의 로고를 원본과 대조한다.
- 원본의 형태·비율·여백을 유지한다. 브랜드에서 제공하는 밝은 배경·어두운 배경용 버전을 사용하며, 채널 팔레트에 맞추려고 로고를 임의로 다시 칠하지 않는다. 로고를 늘이거나 자르고 과도한 효과로 변형하지 않는다.
- 로고와 큰 제목의 위계를 구분한다. 오늘AI 채널 표시와 소개하는 서비스의 로고가 서로 가리거나 공식 협업·보증 표시처럼 보이지 않게 배치한다.

## 타이포그래피와 자막

- 기본 폰트는 스킬의 `assets/fonts/`에 있다. 제목은 Paperlogy ExtraBold/Bold, 본문·자막은 Regular/Medium을 사용한다.
- 광양 감동체는 짧은 손글씨 주석에 사용한다. 긴 본문이나 지속되는 자막용으로 사용하지 않는다.
- 실제 로컬 폰트를 로드한다. 렌더 환경의 폰트 대체 여부를 확인한다. 기존 프로젝트의 WOFF2가 있으면 재사용한다.
- 제목은 핵심 단어가 한 번에 읽히도록 짧게 만든다. 내용량을 맞추기 위해 글자를 계속 줄이지 않는다.
- 자막은 뜻이 이어지는 단위로 직접 나눈다. 조사·짧은 어미가 홀로 다음 줄에 남지 않도록 고친다.
- 숏폼 자막은 최대 2줄을 출발점으로 하고, 초과하면 의미 단위로 큐를 나눈다. 행 수만 맞추려고 문장을 끊지 않는다.
- 하단 날짜·제작용 페이지 번호·출처 코드·강사 메모를 상시 표기하지 않는다. 발표일이나 사용 조건은 내용에 필요한 장면에서 읽을 수 있게 전달한다.
- 자간·행간·상하 여백을 실제 출력 크기와 휴대폰 크기로 검토한다. 유튜브·릴스 버튼 영역과 겹치지 않도록 현재 화면을 기준으로 잡는다.
- 참고 시작값: 1920×1080 롱폼 자막 37px / 행간 1.6 / 자간 1px, 1080×1920 숏폼 42px / 행간 1.65 / 자간 1.1px. 글꼴과 내용에 따라 조정하며 고정 규격으로 취급하지 않는다.
- 단어·구 단위로 써지는 타이틀은 가능하다. 음성을 따라 읽어야 하는 자막은 문구 단위로 안정적으로 유지한다.

## 모션 요소의 공통 문법

장면 전체의 구성, 일러스트·픽토그램, 텍스트·박스의 표현, 연결 방식은 [모션 연출 기준](motion-direction.md)을 함께 적용한다. 아래 규칙만 지키고 매 장면을 같은 카드 틀로 만들면 충분하지 않다.

사용자 레퍼런스에서 정리한 선·모션 기준과 `assets/boards/`를 참고한다. 별도 레퍼런스 원본이 제공되면 필요한 부분을 직접 확인한다. 타인의 원본 영상은 이 공개 패키지에 포함하지 않는다.

| 요소 | 역할 | 시작 조건 |
| --- | --- | --- |
| 굵은 마커 밑줄 | 중요한 단어 한 구절 강조 | 대상 글자가 나타나고 위치가 안정된 후 |
| 손으로 그리는 동그라미 | 결과값·버튼·핵심 영역 지정 | 해당 대상이 보이고 나레이션이 언급할 때 |
| 화살표 | 설명 문구와 실제 위치 연결 | 출발·도착 대상이 둘 다 존재할 때 |
| 설명 일러스트 | 과정·관계 설명 | 나레이션의 의미 단위에 맞춰 순차 드로잉 |
| 실사 위 스케치 | 실제 사진·화면의 관찰 지점 표시 | 원래 장면을 인지할 시간을 준 다음 |
| 전환 | 다음 이야기로 연결 | 문장이 끝나고 필요한 읽기·쉼이 확보된 다음 |

- 선 두께, 둥근 끝, 그리는 속도, 곡선 성격을 컴포넌트 토큰으로 통일한다. 해상도가 다른 출력에는 비례 조정한다.
- 장면 전체를 계속 움직이지 않는다. 먼저 보여주고, 핵심만 움직이고, 읽을 시간을 준다.
- 효과의 시작점은 대상 요소의 등장 완료 시각과 음성 큐로 정한다. 모든 장면에 같은 고정 지연을 넣는 방식은 피한다.
- 대상의 bounding box에 밑줄과 화살표를 연결한다. 자막 줄바꿈이나 글자 크기가 바뀌면 위치도 갱신한다.
- 밑줄은 전체 박스가 아닌 실제 강조 구절의 폭에 맞춘다. 둥근 선 끝의 여백, 폰트 로드, SVG 경로 단위와 최종 MP4의 시작·중간·완료 프레임까지 [정밀 검수 기준](precision-checks.md)에 따라 확인한다.
- 강조 효과 시작 직전과 직후 프레임을 확인한다. 텍스트보다 먼저 튀어나오는 장식, 엉뚱한 단어를 가리는 선을 수정한다.
- 쉬는 구간에는 시선을 붙잡으려고 새로운 문장이나 장식을 추가하지 않는다. 현재 결과를 읽고 이해할 수 있게 유지한다.
- 관심을 유지할 때는 결과 확대, 입력과 결과 비교, 단계적 노출처럼 정보가 달라지는 전환을 쓴다. 의미 없는 흔들기나 과한 확대·축소를 반복하지 않는다.
- “읽는 동안 유지”를 장면 전체의 정지로 해석하지 않는다. 설명이 진행되는 동안 입력이 결과로 바뀌는 과정, 정보를 연결하는 선, 필요한 부분으로 시선을 옮기는 구성을 보여주고, 핵심을 읽는 순간과 승인된 쉼 구간에 멈춘다.

## 캐릭터

- 승인 기준 이미지: `assets/character/reference-approved.png`.
- 사용자 자신을 대표하는 캐릭터다. 짧은 검정 웨이브 머리, 흰 셔츠와 접은 소매, 검정 바지, 노트의 기본 정체성을 유지한다.
- **항상 등장할 필요가 없다.** 주의 환기, 직접 가리키기, 한 번의 설명 등 등장 이유가 있을 때 배치한다.
- 눈·고개·팔을 따로 움직이고 동작 사이에 쉼을 둔다. 표정·포즈의 의미를 나레이션과 맞춘다.
- 통짜 이미지를 상하로 흔들거나 계속 떠다니게 하는 동작은 자연스러운 캐릭터 연기로 취급하지 않는다.
- 기존 로컬 Lottie 실험본은 본편 승인본이 아니다. 승인 캐릭터의 외형과 미승인 애니메이션을 혼동하지 않는다.

## 보드 요청을 받은 경우

다음 요소를 한눈에 비교할 수 있게 실제 시안으로 만든다. 단순한 텍스트 설명으로 완료하지 않는다.

1. HEX가 표시된 색상과 밝은/어두운 배경 배색 예시.
2. 제목·본문·자막·손글씨 주석의 실제 폰트와 크기 계층.
3. 아이콘·밑줄·화살표·동그라미의 일관된 선과 사용 예시.
4. 공식 화면, 결과 화면, 실사 위 스케치의 조합.
5. 핵심 프레임과 순서가 있는 모션 미니 시안.
6. 캐릭터가 요청되었다면 승인 외형을 유지한 표정·포즈와 등장 조건.

정적 보드와 움직임 검토본을 구분한다. 음성 포함을 요청받은 시안은 실제 음성 트랙을 넣는다.
