# PC 앱에 붙여넣을 작업 지시문

## 시작 전 체크 (직접 하기)
1. Claude 데스크톱 앱 → 설정 → Desktop app → **Computer use 켜기**
2. Chrome에 **Claude in Chrome** 확장 연결 (웹 화면 클릭·입력용)
3. ChatGPT, 노션, PlayMCP(playmcp.kakao.com) **미리 로그인**
4. Gemini API 키를 PC 환경 변수 `GEMINI_API_KEY`에 저장 (채팅창에 붙여넣지 않기)
5. 화면 녹화 도구 준비 (Windows: Win+Alt+R 또는 OBS / Mac: Cmd+Shift+5)
6. 저장소 `bekind2all/youtube_create` 폴더를 열어둔 상태로 시작

## ▼ 아래 전체를 복사해서 붙여넣기

```
youtube_create 저장소의 youtube-motion 스킬과 기존 규칙(docs, references)을 먼저 읽고 그 방식대로 영상 1편을 만들어줘.

[주제]
ChatGPT에 노션 MCP와 PlayMCP(카카오)를 연결하는 방법. 실제 연결 화면을 직접 조작하며 녹화한 화면 중심 튜토리얼.

[스타일 레퍼런스: AI 투데이 "플리 만들어줘" 영상 인트로 분석 결과]
- 장면당 3~6초, 내레이션 한 문장 = 그래픽 하나
- 평면(플랫) 아이콘 + 흰 카드, 무채색 위에 강조색 하나만 사용
- 커서가 다가와 클릭하는 연출 반복 ("누르기만 하면 된다")
- 체크 표시·박스·카드가 하나씩 순서대로 등장
- 타이핑 효과 텍스트, 진행 바, 토글 스위치 켜짐, 묶음 괄호, 큰 숫자 하나로 메시지 전달
- 흐름: 공감 훅 → 문제 제시 → 도구 공개 → 핵심 3가지 → 결과 → 혜택 예고 → 채널 로고

[브랜드]
- 채널명/로고: 오늘AI (로고 이미지는 저장소 brand 폴더 또는 내가 첨부한 파일 사용)
- 색상: 검정 #000000 / 네이비 #14213D / 주황(강조) #FCA311 / 연회색 배경 #E5E5E5 / 흰색 #FFFFFF
- 레퍼런스의 빨강 강조 역할은 주황 #FCA311이 맡음
- 실제 색상값은 brand.json과 대조해서 다르면 나에게 알려줘

[작업 순서 - 단계마다 나에게 확인받고 진행]
1. 대본: 인트로(약 50초) + 본편(ChatGPT 노션 MCP 연결 → PlayMCP 연결 → 실제로 써보는 예시 1개) + 마무리. 과장·수익 보장 표현 금지.
2. 녹화 순서표: 화면마다 [어디서 / 무엇을 클릭·입력 / 대본 몇 번 문장]을 표로.
3. 화면 녹화: 컴퓨터 유즈와 Claude in Chrome으로 순서표대로 조작. 로그인·권한 허용·결제 버튼은 누르지 말고 나에게 요청. 실제 메뉴 이름·위치는 화면을 보고 확인해서 순서표를 수정.
4. 내 녹화 파일 확인: 개인정보(이메일, 워크스페이스명, 토큰)가 보이는 구간 목록 작성 → 모자이크 처리.
5. 음성: 저장소의 google_tts.py로 Gemini TTS 생성 (예전에 쓰던 내 목소리 설정 그대로). 키는 출력하지 말 것.
6. 편집: 인트로 모션그래픽 + 녹화 화면에 단계 자막, 클릭 위치 강조 원, 확대(줌), 주황 강조 적용. 1920x1080, 30fps MP4.
7. 썸네일 1장과 유튜브 제목 후보 3개.

[주의]
- 파일 삭제 전에는 반드시 나에게 물어볼 것
- 나는 비개발자라서 각 단계 끝에 핵심 내용과 용어를 짧게 정리해줄 것
```

## 용어
- **MCP**: AI(ChatGPT·Claude)가 노션·카카오 같은 외부 서비스와 연결되는 통로 규격
- **컴퓨터 유즈**: Claude가 내 PC 화면을 보고 마우스·키보드를 대신 조작하는 기능
- **Claude in Chrome**: 웹사이트를 Claude가 클릭·입력할 수 있게 해주는 크롬 확장
- **환경 변수**: 프로그램이 읽는 설정값. API 키를 안전하게 보관하는 곳
