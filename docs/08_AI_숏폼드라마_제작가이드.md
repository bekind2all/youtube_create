# AI 숏폼 드라마 제작 가이드 (원카AI 영상 기준)

작성일 2026-10-06. 대상 영상: [99%는 모르는 AI 드라마 제작법, 업스케일로 크레딧 반값에 만드세요 (ft.시댄스2.5, Newtake)](https://www.youtube.com/watch?v=rgiVS19DE-Q) (원카AI, 28:20).

## 근거 구분

- **확인됨**: 사용자가 별도로 확인한 한국어 자막과 화면(프롬프트 입력창, 비용표)
- **재구성**: 영상의 작업 방식을 따라 하도록 새로 쓴 문구. 제작자 원문이 아님
- **미확보**: 제작자가 카카오톡 채널 친구 추가 후 배포하는 전체 프롬프트 자료

참고 영상 [AI 숏드라마 제작, 이렇게 하면 됩니다](https://www.youtube.com/watch?v=BNpEhKQ0bME) (이든, 10:28)는 제목과 설명란만 확인했다. 장면 이미지를 먼저 만든 뒤 영상으로 바꾸는 방식이라 이 문서의 기본 흐름과 다르다. 처음 연습할 때 보조로 참고한다.


## 4. 비용표 읽는 법

| 항목 | 화면상 계산 | 크레딧 |
|---|---|---:|
| 영상 생성 | 30초 영상 12개 × 600 (3개 실패·미사용) | 7,200 |
| 2K 업스케일 | 사용한 9개 × 217 | 1,953 |
| 이미지 | 40장 × 15 | 600 |
| 항목 합계 | | **9,753** |

- 화면의 총합은 **8,534**로 항목 합계와 1,219 차이가 난다. 예산은 9,753 쪽으로 잡는 것이 안전하다.
- 시연 당시 단가: 720p 생성 1,380 / 480p 생성 600 / 1080p 업스케일 124 / 2K 업스케일 217.
- 480p 생성 후 1080p 업스케일은 724로 720p 직접 생성 대비 약 48% 절감, 2K 업스케일은 817로 약 41% 절감.
- 진짜 절감은 실패한 결과를 업스케일하지 않는 데서 나온다. 가격은 바뀔 수 있으니 생성 버튼의 크레딧 표시로 다시 확인한다.

## 5. 반드시 고려할 점

영상에서 강조한 것:

1. 기획이 8할이다. 매 화 끝에 다음 화가 궁금한 장치를 넣는다.
2. 전편을 한 번에 만들지 말고 첫 30초만 테스트한다.
3. 캐릭터는 이름만 쓰지 말고 노드나 이미지를 실제 참조로 연결한다.
4. 카메라는 생성 전에 설계한다. "영상은 아직이야"로 생성을 막고 먼저 고친다.
5. BGM 제거는 결과로 확인한다. 남아 있으면 보컬 추출을 쓴다.
6. 앞 장면 프레임을 다음 장면의 참조로 넣어 배경·조명·소품을 이어 간다.
7. 캐릭터 등록 시 이미지 사용 권리를 확인한다.

추가 실무 체크:

1. **화면 비율**: 영상 예시는 캐릭터 9:16, 영상 16:9다. 세로 쇼츠라면 영상 비율을 처음부터 9:16으로 지정한다.
2. **30초 한 개와 30초 구간은 다르다**: 에이전트도 처음엔 3개로 나눠 합치자고 제안했다. 모델이 한 번에 생성할 수 있는 길이를 먼저 확인한다.
3. **업스케일은 내용 오류를 고치지 못한다**: 얼굴 변화, 손, 소품, 연기를 먼저 검수한다.
4. **대사 언어와 화자 명시**: 영어 프롬프트에서도 대사는 원문 그대로 두고 누가 말하는지 적는다.
5. **대사 길이**: 짧은 컷에 긴 대사를 넣으면 말이 빨라지거나 잘린다.
6. **목소리 일관성**: 장면마다 음색·말투·볼륨이 바뀌지 않는지 확인한다.
7. **보컬 추출의 부작용**: 발소리·문소리도 사라질 수 있으니 편집에서 보완한다.
8. **에이전트 통제**: "아직 생성하지 마"를 넣고 클립 수와 예상 크레딧을 본 뒤 진행한다.
9. **권리와 표기**: 유명 캐릭터·실존 인물·브랜드는 쓰지 않는다. YouTube 업로드 시 AI 생성(합성) 콘텐츠 표시를 켠다.
10. **모델 평가**: 시댄스가 낫다는 평가는 제작자 의견이다. 장면마다 다를 수 있다.
