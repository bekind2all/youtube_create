# 소유자 전용 백업

`owner-private.ymenc`에는 본인 음성의 원본 OGG 2개(참고 음성·동의 녹음), 처리한 참고 WAV·동의 WAV, 등록된 Google 음성 프로필, 승인된 발화 속도 참고 음성이 들어 있습니다.

API 키와 복호화 키는 포함하지 않았습니다. 복호화 키를 가진 사람은 음성 원본에 접근할 수 있으므로, 키는 개인 비밀번호 관리자나 별도 보호된 저장소로 옮기세요.

복원 명령은 루트 [README](../README.md)를 참고하세요. 원본 녹음은 백업과 재등록 대비용이며, 동일 프로필에 대한 새 나레이션 생성 때 매번 다시 업로드하는 자료가 아닙니다.

복원 후에도 Google 측 동일 프로젝트·권한과 현재 API 지원이 필요합니다. 이 백업은 클라우드 계정이나 API 사용 권한을 대체하지 않습니다.
